# Snapdeal Product Analytics — Internship Project

Power BI dashboard analyzing Snapdeal product listing data: pricing vs. satisfaction exceptions, discount trends, rating trust-weighting, and dynamic price banding.

## Contents
- `snapdeal_products.csv` — raw scraped dataset (5,660 rows, single scraping session)
- `snapdeal.py` — Selenium-based scraper source code
- `Project_Report.md` — full internship report (added at project completion)

## Status
🚧 In progress — dashboard being built in Power BI Desktop.

## Data Limitations
This dataset does not contain Sales, Stock Value, Return Rate, or Promotion Flag fields. Tasks requiring these fields are documented as partial/unsupported analyses rather than fabricated. See `Project_Report.md` for full details once added.
